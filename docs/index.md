# Autoscout - AI-Driven Recon & Vulnerability Analysis Framework

Welcome to the official documentation for Autoscout. This guide provides a detailed walkthrough of the high-fidelity Terminal User Interface (TUI) and its professional-grade features.

## 🚀 Key Features

### 1. Unified Session Management (File ⊞)
Autoscout now supports persistent, named investigation sessions.
- **Persistent Storage**: All investigation data is stored in `~/.autoscout/sessions/<SessionName>/`.
- **Session Manager**: Accessible via the **File** tab or by pressing **`s`** from the Proxy panel.
- **Workflow**: Easily switch between different targets without losing your captured traffic or AI analysis history.

### 2. High-Fidelity Proxy Panel (⇆)
Monitor real-time traffic intercepted from Burp Suite.
- **Live Interception**: View HTTP requests and responses as they happen.
- **Color-Coded Triage**: Methods (`GET`, `POST`, etc.) and status codes are color-coded for rapid analysis.
- **Instant Forwarding**: Select any entry and press **`Enter`** to open it in the deep-analysis modal.
- **Interactivity**: Support for **`d`** (Delete individual) and **`c`** (Clear all).

### 3. Pro-Tier Investigation Modal
A high-fidelity modal for deep forensic investigation of specific requests.
- **Tabbed View**: Switch between **REQUEST**, **RESPONSE**, and **AI ANALYSIS** using **Tab** or a **Mouse Click**.
- **Fixed Scrolling**: Intelligent line wrapping ensures that even massive headers (like cookies) are scrollable with **`j/k`**.
- **Chat Persistence**: Your conversation with the AI is saved as `<RequestID>.chat.json` and restored automatically when you reopen the request.
- **Visual Feedback**: Real-time progress spinners indicate when the AI backend is thinking.

### 4. AI-Driven Analysis
Powered by your local **Codex Agent** or centralized backends.
- **System Codex**: Strictly integrated with the `codex` binary for high-performance OpenAI/ChatGPT-tier analysis.
- **Automated Planning**: The AI suggests specific tools (`sqlmap`, `nuclei`, etc.) based on patterns detected in the traffic.

## 🛠 Integration with Burp Suite
1. Load the generated `autoscout-burp.jar` extension into Burp Suite.
2. In the "Autoscout" tab -> **Settings**, set the API Endpoint to `http://localhost:8081`.
3. Right-click any request in Burp and select **"Send to Autoscout"**.
